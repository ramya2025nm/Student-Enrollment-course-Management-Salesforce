# Student Enrollment & Course Management - Salesforce
Created by Ramya S | ramya2025nm

## Project Overview
This is a Salesforce-based system to manage Students, Courses, Instructors and Enrollments.

## Objects Created
- Student__c - Student details
- Course__c - Course details  
- Instructor__c - Instructor details (NEW)
- Enrollment__c - Connects Student & Course

## Key Features
- Lookup Relationships
- Validation Rules: Email_Must_Be_Student_Domain, Fess_Must_Be_Paid_Before_Approval
- Approval Process: Approval_Enrollment_Request
- Field Updates: Approved & Rejected Status
